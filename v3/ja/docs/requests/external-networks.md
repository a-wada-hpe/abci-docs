# 外部ネットワークとの通信の申請

ABCIと外部ネットワーク上のサービスやサーバとの間の通信は一部のみ許可されています。許可されている通信は以下のとおりです。

| 接続元 | 接続先 | ポート | サービスネーム |
|:--|:--|:--|:--|
| 外部ネットワーク | 計算ノード | すべて禁止 | |
| 計算ノード | 外部ネットワーク | 22/tcp | ssh |
| 計算ノード | 外部ネットワーク | 53/tcp | dns |
| 計算ノード | 外部ネットワーク | 80/tcp | http |
| 計算ノード | 外部ネットワーク | 443/tcp | https |

上記の表で許可されている通信以外の計算ノードから外部ネットワークへの通信については、通信許可の申請を受け付けています。申請が審査され承認された場合には、年度末まで通信許可を設定します。ただし、審査の結果、必ずしもご希望に沿えない場合があります。

申請に先立って通信の許可を検討するための情報として、次の情報を添えて <abci3-qa@abci.ai> 宛にメールしてください。その他の情報を追加でお聞きすることがありますので、ご理解・ご協力の程、お願いいたします。

```
[氏名]: 
[ABCIアカウント名]: 
[ABCIグループ名]: 
[登録されている所属機関]: 
[登録されているメールアドレス]: 

* 通信先のサーバの名称、IPアドレス/hostname、役割、管理者（または管理している法人）
* 通信先のポート番号
* 通信を希望する期間（開始日～終了日）
* 通信する目的
* サーバ名・ポート番号が、目的を達成するために必要であることを説明する文書またはURL等
```

上記が承認された後、ABCIグループの利用責任者からABCIサポートへ通信の許可依頼を申請してください。または、ABCIグループの利用責任者から承認を得たことがわかる文書を添付し、かつ、CCに利用責任者を付けた上で申請してください。

通信許可の申請方法は[お問い合わせ](../contact.md)のページを参照してください。なお、申請審査に2週間～4週間かかりますので、余裕をもっての申請をお願いいたします。

外部ネットワークとの通信は、継続・新規利用申請され承認されたABCIグループのみ、通信許可を設定します。ただし、継続・新規利用申請の前に、通信許可について申請することは可能です。
